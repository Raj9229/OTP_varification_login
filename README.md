# OTP Verification Login System

A simple and secure OTP (One-Time Password) verification system for user authentication.

## Overview

This project implements a lightweight authentication system that utilizes one-time passwords for enhanced security. The system includes user registration, login, and OTP verification features that can be easily integrated into web applications.

## Features

- **User Registration**: Simple sign-up process to create new accounts
- **OTP Generation**: Secure generation of time-based one-time passwords
- **OTP Verification**: Validation mechanism for verifying entered OTPs
- **Responsive Design**: Works seamlessly across various device sizes

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/Raj9229/OTP_varification_login.git
   ```
2. Navigate to the project directory:
   ```
   cd OTP_varification_login
   ```
3. Open `index.html` in your browser to start using the application.

## How It Works

1. User registers with their details
2. On login attempt, an OTP is generated and sent to the user's registered email/phone
3. User enters the received OTP to complete authentication
4. Upon successful verification, user gains access to the protected content
